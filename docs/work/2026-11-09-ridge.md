# Gaussian ridge and CV, 0.8.0

Implemented fit_ridge/RidgeFit and cv_ridge in native phit and the pure PHP
polyfill. Explicit lambda follows observed Gaussian glmnet response scaling;
the original plan's simplified objective needed lambda/response_scale. The
clean-room ridge specification records this, no-intercept scaling, weighted CV,
MASS conversion, and lmridge variance differences. No reference package source
was read. Conditional SEs are included by default with bias and coverage caveats;
at-bound uncertainty is null. Default paths use 100 values from 100*sy to .01*sy.
Robust covariance remains step 3.

Validation uses 12 fit and 6 CV fixtures from glmnet 5.1, MASS 7.3.65,
lmridge 1.2.2, and independent R matrix formulas. Both implementations pass
5,988 numerical comparisons. Maximum absolute difference is 6.855e-8;
maximum tolerance fraction is .589 under atol 1e-7, rtol 2e-6. The heating
reference uses thresh=1e-18 after thresh=1e-14 left stopping differences of
a few millionths. Day folds and age-decaying weights are combined explicitly.
An independent scientific review found an equality-bound initialization issue;
fixed coordinates are now removed from the initial QR and KKT solve.

Ridge-only benchmarks use seven fresh-process repetitions after an excluded
warm-up and rotate execution order. They cover simple and heating fits,
1,152 rows, and weighted CV. R glmnet does less work because it does not compute
conditional covariance. Actual timings and source hashes are in
bench/ridge-results.json. No unrelated benchmarks were rerun.

Validation: PHP 8.4 NTS scripts/check passed; focused polyfill ridge, API,
fit objects, summary, and prediction tests passed (131 tests, 8,872 assertions).
Both repositories pass PHPCS. Generated documentation and reference hashes
passed. The optional phibble CSV integration is skipped by scripts/check when
PHIBBLE_AUTOLOAD is unset. Release CI handles Linux PHP 8.3–8.5 binaries.
