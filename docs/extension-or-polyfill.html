Extension or polyfill

phit has two implementations of the Phit\ functions. Code written against one runs unchanged on the other, unless it reads CSV files through phit.

Extension Polyfill
Package phpstats/phit phpstats/phit-polyfill
Implementation Compiled Rust, installed into PHP Plain PHP, installed with Composer
Install PIE or a prebuilt binary (Installation) composer require phpstats/phit-polyfill
Functions All All except read_csv() and CsvReader
PHP 8.3, 8.4, 8.5 (NTS) on Linux and macOS ^8.3; CI on Linux and macOS, Windows untested
OPcache JIT Runs under any setting Refuses to run while the JIT compiles the process
Speed Faster Slower; the gap grows with model size

Versions

Each polyfill release reproduces one phit release. Polyfill 0.4.2 reproduces phit v0.4.4 and provides 242 of its 243 functions, including the deprecated aliases.

How they coexist

  • Composer loads the polyfill’s bootstrap.php through its files autoload. If extension_loaded('phit') is true, the bootstrap defines nothing, so every Phit\ function is the extension’s. Installing both is safe.
  • The polyfill does not fill gaps in an older extension. If the loaded extension is older than the polyfill’s phit release, functions added since then stay undefined.
  • The polyfill’s composer.json declares "provide": {"ext-phit": "*"}, so it satisfies a package that requires ext-phit, including one that uses the CSV reader.
  • Without the extension, function_exists('Phit\read_csv') and class_exists('Phit\CsvReader') return false, as does Phit\Polyfill::supports('Phit\read_csv'). phibble’s DataFrame::fromCsv() then uses its own PHP reader.

Coverage

Area Polyfill
Formula models and prediction model_matrix, fit_ols, fit_generalized_linear, fit_mixed_gaussian, fit_mixed_logistic, and predict, with a port of the formula parser
Matrix models All *_matrix functions
Mixed models The same structures as the extension. fit_mixed_gaussian: random intercepts and slopes, (x || g), several terms, and nesting, by REML or ML with BOBYQA or Nelder–Mead. fit_mixed_logistic: one binomial logit (1 | g), by Laplace or adaptive quadrature with up to 61 points.
Distributions, descriptive statistics, seeded sampling All functions
Posterior-draw kernels draws_moments, draws_covariance_map, and draws_affine
CSV input Not provided

The polyfill’s tests run the extension’s reference fixtures, including the lme4 and seeded-sampling references, at the extension’s tolerances, plus randomized parity tests against the extension.

Differences

  • The listwise-deletion warning is E_USER_WARNING in the polyfill and E_WARNING in the extension. The text is the same.
  • Arguments of the wrong scalar type follow PHP’s userland rules in the polyfill: coercion, or a TypeError under strict_types.
  • Every polyfill function throws an exception with code 1007 while OPcache’s JIT compiles the process, because the JIT has produced wrong numerical results in the polyfill. The JIT is off by default in PHP 8.4 and 8.5, and PHP 8.3’s defaults (opcache.jit=tracing with opcache.jit_buffer_size=0) also leave it off.
  • On an x86-64 CPU without fused multiply-add, the extension’s products of matrices larger than 5×5 can differ from the polyfill’s in the last bit.

Speed

The benchmarks time each workload with the extension and with the polyfill.

The polyfill’s own documentation is in the phit-polyfill repository.
