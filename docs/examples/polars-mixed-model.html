Fit a mixed model to a Polars table and chart it

This example reads a CSV file with Polars, fits test scores with a random intercept for each school using fit_lmer(), and charts each school’s fitted line with phiz.

Requires the phit extension (Installation), the phpolars extension (phpolars installation), and phiz from Composer (composer require phpstats/phiz).

Data

The data are 250 simulated students in 12 schools, in docs/data/schools.csv. score is a test score in points, and study_hours is time spent studying, in hours. Save the file beside the script:

curl -O \
  https://raw.githubusercontent.com/phpstats/phit/main/docs/data/schools.csv

Code

<?php
require 'vendor/autoload.php';

use Phiz\Plot;

use function Phit\fit_lmer;
use function Phpolars\scan_csv;

// 1. Read three columns with Polars and copy them into PHP arrays once.
$schools = scan_csv('schools.csv')
    ->select(['school', 'study_hours', 'score'])
    ->collect();
$data = $schools->toColumns();

// 2. Fit a random intercept per school by REML. Keep the fitted values.
$fit = fit_lmer('score ~ study_hours + (1 | school)', $data);
$data['fitted'] = $fit['fitted'];

foreach ($fit['columns'] as $i => $name) {
    printf("%-12s %7.3f (se %.3f)\n", $name,
        $fit['coefficients'][$i], $fit['std_errors'][$i]);
}
$school = $fit['random'][0];
printf("%s: school SD %.3f, residual SD %.3f\n", $fit['method'],
    sqrt($school['covariance'][0][0]), $fit['sigma']);
printf("%d students in %d schools\n",
    $fit['n_observations'], count($school['group_labels']));

// 3. Chart the students as points and each school's fitted line.
$chart = Plot::of($data)
    ->aes(x: 'study_hours', y: 'score')
    ->point(alpha: 0.3)
    ->line(aes: ['y' => 'fitted', 'group' => 'school'], alpha: 0.6)
    ->labs(x: 'Study hours', y: 'Test score');

file_put_contents('schools.html', $chart->html('Scores by school'));

Output

(Intercept)   56.493 (se 1.541)
study_hours    2.343 (se 0.109)
REML: school SD 4.568, residual SD 5.394
250 students in 12 schools

Explanation

The script has three steps.

  1. scan_csv() starts a lazy query, select() keeps three of the file’s four columns, and collect() runs it. toColumns() copies the result into PHP arrays, one per column. fit_lmer() and Plot::of() both accept an object with toColumns() and would each call it themselves, so the script calls it once and passes the arrays to both.
  2. fit_lmer() fits score ~ study_hours + (1 | school) by REML, as lme4::lmer() does by default. Within a school, each additional study hour is associated with a score about 2.3 points higher. School intercepts vary with a standard deviation of about 4.6 points around the average of 56.5 at zero hours. fitted holds the conditional fitted values, which include each school’s random intercept.
  3. phiz draws every student as a point and joins each school’s fitted values into a line. The model gives every school the same slope, so the twelve lines are parallel and differ only by their intercepts. The script saves the chart as a standalone page, schools.html.

See Fit a mixed model for reading the variance components and school effects, Mixed models for the supported structures, phpolars’ Getting started for lazy queries, and phiz’s Get started for layers and aesthetics.
