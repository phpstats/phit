Fit a mixed model to a Polars table and chart it

Read a CSV file with Polars, fit test scores with a random intercept for each school, and chart each school’s fitted line with phiz.

The example needs the phpolars extension (phpolars installation) and phiz (composer require phpstats/phiz). phit can be the extension or the plain-PHP polyfill (Extension or polyfill). Runnable script

Data

The data are 250 simulated students in 12 schools, in docs/data/schools.csv. score is a test score in points, and study_hours is time spent studying, in hours. Save the file beside the script:

curl -O \
  https://raw.githubusercontent.com/phpstats/phit/main/docs/data/schools.csv

Code

use Phiz\Plot;

use function Phit\fit_mixed_gaussian;
use function Phpolars\scan_csv;

$data = scan_csv('schools.csv')
    ->select(['school', 'study_hours', 'score'])
    ->collect()
    ->toColumns();

// A random intercept per school, fitted by REML.
$fit = fit_mixed_gaussian(
    'score ~ study_hours + (1 | school)',
    $data,
);
$data['fitted'] = $fit['fitted'];

foreach ($fit['columns'] as $i => $name) {
    printf(
        "%-12s %7.3f (se %.3f)\n",
        $name,
        $fit['coefficients'][$i],
        $fit['std_errors'][$i],
    );
}
printf(
    "school SD %.3f, residual SD %.3f\n",
    sqrt($fit['random'][0]['covariance'][0][0]),
    $fit['sigma'],
);

// Students as points, and one fitted line per school.
$chart = Plot::of($data)
    ->aes(x: 'study_hours', y: 'score')
    ->point(alpha: 0.3)
    ->line(
        aes: ['y' => 'fitted', 'group' => 'school'],
        alpha: 0.6,
    )
    ->labs(x: 'Study hours', y: 'Test score')
    ->theme(baseSize: 15)
    ->size('container', 380);

file_put_contents(
    'schools.html',
    $chart->html('Scores by school'),
);

Output

(Intercept)   56.493 (se 1.541)
study_hours    2.343 (se 0.109)
school SD 4.568, residual SD 5.394

Interpretation

  • toColumns() converts the Polars result to PHP arrays once for use by phit and phiz.
  • The study_hours coefficient is an association within schools.
  • fitted holds conditional fitted values, which include each school’s predicted intercept. fixed_fitted leaves them out.
  • The model gives every school the same slope, so the fitted lines are parallel.
