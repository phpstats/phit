Descriptive statistics

Summarize PHP numeric arrays: means, variances, covariance and correlation, quantiles, weighted moments, kernel density estimates, interpolation, and the empirical CDF. The functions are stateless and return floats or packed lists.

$values = [2.5, 3.1, 4.7, 1.2, 9.8, 5.5, 3.3];

Phit\stat_mean($values);                         // 4.3
Phit\stat_var($values);                          // 7.85667
// [2.8, 3.3, 5.1]
Phit\stat_quantile_array($values, [.25, .5, .75]);
Phit\stat_mean([1, null, 3], missing: 'drop');   // 2.0
  • Array keys are ignored. Iteration order aligns pairs and weights.
  • Every function except stat_quantile_array, stat_density, stat_approx, and stat_ecdf returns a float.

Quantiles

Quantiles use R’s default type 7. For sorted values x, let h = 1 + (n − 1)p and interpolate between the adjacent values using the fractional part of h.

  • p must be in [0, 1]. p = 0 and p = 1 give the minimum and maximum.
  • The median is the type-7 quantile at p = 0.5.
  • stat_quantile_array sorts once and returns the same values as scalar calls, in the order of the probability array. An empty probability array returns [] after the values are validated.

Weights

Let \(W=\sum_i w_i\), \(m=\sum_i w_i x_i/W\), and \(SS=\sum_i w_i(x_i-m)^2\). Weights must be finite and nonnegative, and the retained total must be positive.

stat_weighted_var type Definition Use
frequency (default) \(SS/(W-1)\) Counts or replication weights; needs W > 1
reliability \(SS/(W-\sum_i w_i^2/W)\) Precision weights; needs a positive denominator
population \(SS/W\) Weighted population second moment
  • Integer frequency weights give the sample variance of the expanded sample.
  • Reliability and population results do not change when all weights are multiplied by a positive constant.
  • Zero weights are allowed. With one effective value, the population variance is 0 and the reliability variance is undefined.
  • A negative weight is rejected even when its paired value is missing. Weights align to original positions before deletion.
  • The draw moments API always normalizes weights and calls reliability normalization 'unbiased'. It never treats weights as counts.

Missing values

Value Default missing: 'raise' missing: 'drop'
null, NAN Exception 1001 Dropped; pairwise for covariance, correlation, and weighted functions
±INF Exception 1003 Exception 1003, even when paired with a missing value
String, boolean, object, nested array Exception 1001 Exception 1001

Dropping is opt-in. Unlike the model functions, these functions return no warning and no row accounting.

Errors

Condition Exception code
Aligned arrays of different original lengths 1002
Unknown type or missing, too few retained values, invalid weights, or p outside [0, 1] 1001
NAN probability 1003
Nonfinite arithmetic result, such as an overflowing weight sum or squared deviation 1003

Correlation of a constant input returns NAN and does not throw.

Sums use Neumaier compensation, and variances and covariances use corrected two-pass centered moments. This keeps accuracy with large common offsets. The calculations are binary64 and have no extended precision.

Density estimation, interpolation, and the ECDF

Five functions follow R’s density(), bw.nrd0(), bw.nrd(), approx(), and ecdf(), with R’s argument names.

$draws = Phit\dist_normal_rng(4000, 7, 0.3, 0.05);
$d = Phit\stat_density($draws);
$at = [0.25, 0.3, 0.35];
$heights = Phit\stat_approx($d['x'], $d['y'], $at);
$below = Phit\stat_ecdf($draws, [0.0]); // Share at or below 0.
Phit\stat_density(array $x, string|float $bw = 'nrd0',
    float $adjust = 1.0, string $kernel = 'gaussian',
    int $n = 512, ?float $from = null, ?float $to = null,
    float $cut = 3.0, ?array $weights = null,
    string $missing = 'raise'): array;
Phit\stat_bw_nrd0(array $x, string $missing = 'raise'): float;
Phit\stat_bw_nrd(array $x, string $missing = 'raise'): float;
Phit\stat_approx(array $x, array $y, array $xout,
    string $method = 'linear', int $rule = 1,
    string $ties = 'mean', float $f = 0.0,
    string $missing = 'raise'): array;
Phit\stat_ecdf(array $x, array $q,
    string $missing = 'raise'): array;

stat_density() returns ['x' => list, 'y' => list, 'bw' => float, 'n' => int]. It follows R’s algorithm: the data are binned linearly onto a grid of at least 512 points (the next power of two above n), convolved with the kernel by FFT, and interpolated onto n points from from to to.

Option Values
bw 'nrd0' (Silverman’s rule, default), 'nrd' (Scott’s variation), or a positive number; multiplied by adjust
kernel gaussian, epanechnikov, rectangular, triangular, biweight, cosine, optcosine
from, to Default to the data range extended by cut bandwidths
weights Used as given, as in R; weights that sum to one are renormalized after missing values are dropped
  • The automatic bandwidths ignore weights, as R’s do.
  • R’s ucv, bcv, and SJ bandwidths are not available.

stat_approx() sorts the points by x and collapses tied x values by ties ('mean', 'min', or 'max').

  • method: 'linear' interpolates linearly. method: 'constant' uses a step function in which f weights the right-hand value.
  • Outside the data range, rule: 1 returns NAN and rule: 2 returns the value at the nearer end.

stat_ecdf() returns the proportion of x at or below each q.

  • x, y, and weights follow the missing-value policy above, and pairs are dropped together.
  • Evaluation points (xout and q) may be infinite. A null or NAN evaluation point returns NAN, as R returns NA.
