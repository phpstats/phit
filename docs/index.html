Project documentation

Fit statistical models directly in PHP using ordinary numeric arrays. The native Rust engine returns coefficients, uncertainty, fitted values, and model statistics. A fixed intercept is added automatically; intercept: false accepts a literal design or fits a model through the origin.

$result = Phit\fit_ols(
    x: [[74.4], [57.4], [66.4], [49.1], [45.7], [92.4], [37.0], [93.9]],
    y: [1879.25, 1805.03, 2022.29, 1267.85, 1509.24, 2240.10, 959.51, 2386.54],
);
// coefficients: approximately [372.478545, 21.479724] — intercept, floor area.

Start with installation and the PHP contracts. For unequal exposure in a Poisson model, pass offset: log(exposure) as an aligned array on the log scale; see the exposure example. Existing callers that supply a ones column should remove it or use intercept: false; random-effect design matrices remain explicit.
