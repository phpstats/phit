Posterior-draw numerical kernels

Compute weighted moments of a draw matrix, a map between two covariance matrices, and an affine transformation of the draws with its log Jacobian. The kernels support PSIS-LOO moment matching in a PHP CmdStan interface, and they work on any numeric matrix with draws in rows.

The caller owns model evaluation, importance ratios, PSIS, iteration control, and diagnostics. The kernels add no fitting, plotting, or model objects.

$draws = [[-3, -5], [0, 1], [2, 3], [5, 8], [1, -2]];
$source = Phit\draws_moments($draws);
$target = Phit\draws_moments(
    $draws,
    weights: [1, 0, 2, 4, 3],
);
$map = Phit\draws_covariance_map(
    $source['covariance'],
    $target['covariance'],
);

$a = $map['matrix'];
$shift = [];
foreach ($a as $j => $row) {
    $mapped = 0.0;
    foreach ($row as $k => $value) {
        $mapped += $value * $source['mean'][$k];
    }
    $shift[] = $target['mean'][$j] - $mapped;
}
$moved = Phit\draws_affine($draws, matrix: $a, shift: $shift);
  • The unweighted moments of $moved['draws'] equal the target moments.
  • $moved['log_abs_det'] is the change-of-variables log Jacobian.
  • The transformation acts in the caller’s parameter coordinates. Constrained Stan parameters and model-specific Jacobians are the caller’s responsibility.
  • The reference lists the result keys and exception codes.

Weighted moments

For \(X\in\mathbb R^{S\times P}\), nonnegative weights are normalized to \(w_i\) with \(\sum_i w_i=1\). weights: null gives \(w_i=1/S\).

\[ \mu=\sum_i w_i x_i,\qquad C_{\mathrm{pop}}=\sum_i w_i(x_i-\mu)(x_i-\mu)^T,\qquad C_{\mathrm{unbiased}}=\frac{C_{\mathrm{pop}}}{1-\sum_i w_i^2}. \]

  • unbiased uses reliability weights, not frequency counts. Multiplying all weights by a positive constant does not change the result.
  • Uniform weights give divisor S for the population covariance and S − 1 for the unbiased covariance.
  • A singular covariance is a valid moment result.
  • Zero-weight rows contribute nothing but are still validated.
  • The unbiased denominator \(1-\sum_i w_i^2\) is computed in binary64. A zero or negative value is rejected, including weights so concentrated that they round to one effective draw. No other effective-sample-size cutoff applies.

Numerical method: weights are divided by their maximum before compensated summation, so weights whose ordinary sum would overflow still work. The mean uses an anchor from a positive-weight draw, a compensated sum of deviations, and a second correction pass. The covariance uses compensated centered cross-products and is returned exactly symmetric. Together these avoid cancellation from a large common offset.

Covariance map

With lower Cholesky factors \(C_s=L_sL_s^T\) and \(C_t=L_tL_t^T\), the map solves

\[ L_s^T A^T=L_t^T,\qquad A C_s A^T=C_t. \]

  • No inverse is formed.
  • The log Jacobian is \(\sum_j\log (L_{t,jj})-\log(L_{s,jj})\), so a very large or small determinant need not be representable.
  • The map depends on parameter order and is one of many covariance maps.

Both covariances must pass a numerical check before factorization. Let \(d_i=\sqrt{C_{ii}}\) and \(R_{ij}=C_{ij}/d_i/d_j\).

  • Each diagonal must be strictly positive.
  • Opposite standardized entries a and b must satisfy \(|a-b|\le64\epsilon\max(1,|a|,|b|)\), with \(\epsilon=2^{-52}\). Accepted asymmetry is averaged on this scale.
  • R must have a Cholesky factor, and each squared diagonal pivot must exceed \(64\epsilon P\). The factor’s rows are then rescaled by \(d_i\).

These checks do not depend on the units of individual parameters. They define a pivot threshold, not a condition-number guarantee, and near the threshold rounding and parameter order can decide acceptance. No jitter, ridge, eigenvalue clipping, or fallback factorization is applied. A singular covariance that draws_moments() returns is therefore rejected by draws_covariance_map().

Affine transformation

Each draw, as a column vector, becomes \(y_i=A x_i+b\). With draws in rows, the implementation computes \(Y=X A^T+\mathbf1 b^T\). No intercept column is added, and draw order is kept.

Invertibility is checked on an equilibrated matrix. Each row of A is divided by its largest absolute element, then each column of the result by its largest absolute element. A zero row or column is singular. The equilibrated matrix B must satisfy

\[ \sigma_{\min}(B)>64\epsilon P\sigma_{\max}(B). \]

  • SVD assesses numerical rank, and pivoted LU supplies the log absolute pivots.
  • The log determinant adds the logs of the row and column scales. Summing logs avoids overflow and underflow, and absolute pivots allow reflections and negative determinants.
  • Scales are applied by division, which handles subnormal values.
  • A numerically singular matrix raises 1004.

Limits

All arithmetic is binary64. Finite inputs can still produce nonfinite intermediate or final values at extreme scales, which raises 1003 rather than returning NAN or INF. Relative accuracy is not guaranteed for underflow-sized covariances or arbitrarily ill-conditioned inputs.

Independent verification

tests/generate-draw-fixtures.py produces 25 cases with Python’s standard-library Decimal at 80 digits. It uses scalar loops for the weighted formulas, a scalar Cholesky and backward solve, and pivoted Gauss–Jordan elimination for reference inverses and log determinants. It never calls the extension or nalgebra.

Quantity Tolerance
All fixture outputs (Rust and PHP) \(10^{-11}+10^{-11}\lvert\mathrm{reference}\rvert\)
Extreme-scale nonzero affine outputs, covariance identities Also relative \(10^{-12}\)
Affine round trips, forward plus reverse log determinants \(10^{-11}+10^{-11}\lvert\mathrm{reference}\rvert\)

The cases cover correlated parameters, uniform, nonuniform, and zero weights, weight rescaling, one effective draw, singular covariance, one parameter, large offsets, mixed units, orientation, reflections, determinant overflow and underflow, invalid arrays, and the thresholds. Rust also checks the weighted covariance transformation under both normalizations. PHP checks named arguments, defaults, iteration order, and strict rejection without missing-row warnings.

tests/fixtures/draws-python.json records the Python version, algorithm, and tolerances, and the provenance manifest hashes the generator and fixture. The regular tests need neither R nor Python.
