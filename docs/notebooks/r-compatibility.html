Expanded R compatibility and all four lme4 optimizers

This notebook executes the installed PHP extension on saved R reference inputs. R generated the checked-in expected values using lm, glm, and lmer with each of its four optimizer wrappers. The two native algorithms are BOBYQA and Nelder–Mead. See the compatibility ledger for supported features and the work still needed for full parity.

Each estimator is fitted with an intercept and without one. Binary estimators include both individual binary responses and grouped success proportions. Weights and offsets affect the fit, covariance, null model and likelihood. We check those quantities rather than testing only unweighted coefficients.

For grouped binomial rows with s successes out of m trials, supply y=s/m and weight=m. R’s equivalent calls are:

A Poisson exposure e contributes log(e) to the linear predictor; a prior weight instead multiplies that observation’s likelihood. Those are different operations. For weighted OLS, residual variance is sigma²/w_i and likelihood includes the weight determinant. Full generator code is in tests/generate-r-compatibility-fixtures.R.

The model suite contains correlated/independent random slopes, crossed and nested terms, a random slope without a random intercept, no fixed intercept, weights and offsets, and an exact zero-variance boundary. The published sleepstudy model is Reaction ~ Days + (Days | Subject), under both ML and REML.

The R generator explicitly selects all four wrappers, tightened stopping controls and boundary.tol=1e-3. The exact per-wrapper settings are recorded in each fixture. Multi-level BOBYQA references also restart from their first R fit with rhobeg=0.001 and rhoend=1e-9: this improved random-effect agreement on a flat likelihood while keeping the comparison tolerances unchanged. Native estimates never seed the R references. At a smaller default boundary tolerance, one wrapper stopped just above a singular boundary; overly strict nlminb settings also produced convergence warnings. The saved audit does not claim identical behavior under every package default.

Likelihoods use 5e-6 + 1e-9 * abs(reference) tolerance. Native/R BOBYQA estimates use 1e-5 + 1e-5 * abs(reference); other optimizer comparisons use 1e-3 + 3e-4 * abs(reference). These admit the observed spread in parameters on a flat likelihood. Shapes, grouping/sample metadata and parameter counts are exact. All rows and raw outputs remain available for inspection.

More than two grouping levels

The fitter accepts a list of random terms; there is no two-level cap. The new synthetic cases use 256 repeated assessments, with 8 districts, 16 schools, 32 classes and 64 students. They fit three grouping levels (district/school/class) and four grouping levels (district/school/class/student), each under ML and REML. The four-level simulation includes independent Gaussian intercepts at all four grouping levels; the three-level simulation omits the student effect. Study hours and practice scores are correlated observed predictors, not initial parameter guesses.

Each random term is independent of the other terms. Dependence between observations arises because they share some group effects. For two observations in the same class but different students, the district, school and class effects are shared; the student effects and observation noise are not.

Provide globally unique nested IDs: the native interface does not infer that a class label belongs to a school. Reusing local class number 1 across schools without a parent-aware key instead specifies a crossed/shared group effect. Three grouping levels plus the observation level are often called a four-level model; we count grouping terms explicitly here to avoid that ambiguity.

$result = stats_lmm_fit(
    x: $fixedDesign,
    y: $scores,
    random: [
        ['z' => $ones, 'groups' => $districtIds],
        ['z' => $ones, 'groups' => $districtSchoolKeys],
        ['z' => $ones, 'groups' => $districtSchoolClassKeys],
        ['z' => $ones, 'groups' => $districtSchoolClassStudentKeys],
    ],
    reml: true,
);

The equivalent R random-intercept specification is (1 | district/school/class/student). Nesting does not introduce a correlation parameter between the levels; each term has its own variance. Random slopes can also be supplied through each term’s z columns, subject to identifiability and size limits. The current dense implementation supports at most 512 total random coefficients and 50,000,000 initial augmented matrix entries.

statsmodels independently estimates ML/REML fixed effects and variance components. For fixed-effect inference we calculate plug-in GLS covariance from its estimates, matching lme4 and our contract; its default joint-Hessian standard errors differ. We require convergence and retain Python warnings. BFGS uses gtol=1e-8; at 1e-10 the REML fit reached the same likelihood but failed its convergence flag, so that failed run was not accepted. Its public MixedLM interface does not provide prior weights, so this Python comparison covers sleepstudy, not the weighted case or every general grouping specification.

figures/sleepstudy-slopes.svg

The observed predictor is days of sleep deprivation; it is not a trial coefficient. Each person’s intercept shifts the line, and their random slope changes its rate of increase. The population line averages over the zero-mean random effects. This model captures individual differences; numerical agreement alone does not establish that the Gaussian assumptions explain the study.
