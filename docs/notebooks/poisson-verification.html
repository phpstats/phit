The same poisson models in R, statsmodels and PHP

We fit the same saved observations and design columns in all three runtimes. See the math walkthrough for how likelihood, Newton updates and normal Wald inference produce these quantities.

from pathlib import Path
import sys
import pandas as pd
ROOT = next(p for p in [Path.cwd(), *Path.cwd().parents] if (p / "Cargo.toml").exists())
sys.path.insert(0, str(ROOT / "docs/verifications"))
from compare_poisson import cases, compare_case
results = [compare_case(case) for case in cases()]
first = results[0]
print(first["versions"])
rows = []
for implementation in ["R", "statsmodels", "php-stats"]:
    fit = first[implementation]
    for j, label in enumerate(["intercept", "visitors", "staff"]):
        rows.append({"implementation": implementation, "coefficient": label,
                     "estimate": fit["coefficients"][j], "SE": fit["std_errors"][j],
                     "z": fit["z_statistics"][j], "p": fit["p_values"][j],
                     "95% lower": fit["conf_int"][j][0], "95% upper": fit["conf_int"][j][1]})
display(pd.DataFrame(rows))
display(pd.DataFrame([{ "case": r["name"], "retained n": r["php-stats"]["n_observations"],
                        "iterations (PHP)": r["php-stats"]["iterations"],
                        "max absolute difference vs R": max(e for values in r["max_absolute_errors_vs_R"].values() for e in values.values()),
                        "warnings": len(r["warnings"])} for r in results]))

Equivalent calls

R adds an intercept in this formula; the other two designs supply it explicitly.

students <- read.csv("docs/data/clinic.csv")
fit <- glm(calls ~ visitors + staff, data=students,
           family=poisson(), control=glm.control(epsilon=1e-16, maxit=100))
coef(fit)
vcov(fit)
confint.default(fit) # normal Wald, not profile likelihood
import statsmodels.api as sm
students = pd.read_csv("docs/data/clinic.csv")
x = sm.add_constant(students[["visitors", "staff"]])
fit = sm.GLM(students["calls"], x, family=sm.families.Poisson()).fit(tol=1e-11, tol_criterion="params", maxiter=100)
fit.params, fit.bse, fit.conf_int()
$x = []; $y = [];
foreach ($students as $student) {
    $x[] = [1.0, $student['visitors'], $student['staff']];
    $y[] = $student['calls'];
}
$result = stats_poisson(x: $x, y: $y);

Here $students contains already numeric records; see examples/poisson.php for the complete CSV conversion and call. The native interface uses no formula parser, implicit column construction or model classes.
