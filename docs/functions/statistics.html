Statistics and optimization functions

Descriptive statistics, density estimation, interpolation, the ECDF, and one-dimensional optimization. Missing values, weights, and errors follow the shared rules.

Summaries

stat_mean()

Arithmetic mean. null/NAN are missing: missing ‘raise’ (default) rejects them, ‘drop’ removes them (pairwise for two arrays). Nonfinite arithmetic raises 1003; constant-input correlation remains NAN.

Phit\stat_mean(
    array $values,
    string $missing = 'raise',
): float
Parameter Type Default Description
$values array required Data; null and NAN are missing
$missing string 'raise' ‘raise’ rejects null and NAN; ‘drop’ removes them, pairwise for aligned inputs

Returns float

Errors Input error (codes 1001–1003).

Smoothing and interpolation

stat_density()

Kernel density estimate as R’s density(): linear binning, FFT convolution, then interpolation onto n points from from to to. bw: ‘nrd0’ (default), ‘nrd’ or a number, multiplied by adjust. Kernels: ‘gaussian’, ‘epanechnikov’, ‘rectangular’, ‘triangular’, ‘biweight’, ‘cosine’, ‘optcosine’. Weights are not normalized; as in R, weights summing to one are renormalized after missing values are dropped. Data arrays: null/NAN are missing, rejected by missing ‘raise’ (default) or removed by ‘drop’; infinite values raise 1003.

Phit\stat_density(
    array $x,
    mixed $bw = 'nrd0',
    float $adjust = 1.0,
    string $kernel = 'gaussian',
    int $n = 512,
    ?float $from = NULL,
    ?float $to = NULL,
    float $cut = 3.0,
    ?array $weights = NULL,
    string $missing = 'raise',
): array
Parameter Type Default Description
$x array required Data; null and NAN are missing
$bw mixed 'nrd0' ‘nrd0’, ‘nrd’ or a positive bandwidth
$adjust float 1.0 Multiplier applied to the bandwidth
$kernel string 'gaussian' ‘gaussian’, ‘epanechnikov’, ‘rectangular’, ‘triangular’, ‘biweight’, ‘cosine’, or ‘optcosine’
$n int 512 Number of output points
$from ?float NULL Left end of the output grid; null extends the data range by cut bandwidths
$to ?float NULL Right end of the output grid; null extends the data range by cut bandwidths
$cut float 3.0 Bandwidths beyond the data range for the default grid
$weights ?array NULL Nonnegative weights aligned with x, used as given; null weights all points equally
$missing string 'raise' ‘raise’ rejects null and NAN; ‘drop’ removes them, pairwise for aligned inputs

Returns array{x: list<float>, y: list<float>, bw: float, n: int}

Errors Input error (codes 1001–1003).

See also Details

stat_approx()

Interpolate (x, y) at xout as R’s approx(): method ‘linear’ or ‘constant’ (f weights the right-hand value), rule 1 gives NAN outside [min(x), max(x)], rule 2 the nearest end value; tied x collapse by ties ‘mean’, ‘min’ or ‘max’. Data arrays: null/NAN are missing, rejected by missing ‘raise’ (default) or removed by ‘drop’; infinite values raise 1003.

Phit\stat_approx(

): array
Parameter Type Default Description

$y array required Ordinates, aligned with x; null and NAN are missing
$xout array required Evaluation points; null or NAN gives NAN
$method string 'linear' ‘linear’ or ‘constant’
$rule int 1 1 returns NAN outside the data range; 2 returns the value at the nearer end

Optimization and root finding

optimize()

Minimize f on [lower, upper] (or maximize, with maximum: true) as R’s optimize(): Brent’s golden-section and parabolic search. Returns ‘minimum’ or ‘maximum’, and the objective f(x). f receives one float and returns an int or float; an exception from f propagates. Nonfinite values during the search are replaced by +/-PHP_FLOAT_MAX, as R does, with one E_WARNING.

Phit\optimize(
    callable $f,
    float $lower,
    float $upper,
    ?float $tol = NULL,
    bool $maximum = false,
): array
Parameter Type Default Description
$f callable required Objective: takes one float and returns an int or float
$lower float required Lower end of the search interval
$upper float required Upper end of the search interval
$tol ?float NULL Default PHP_FLOAT_EPSILON ** 0.25, as R
$maximum bool false Maximize instead of minimize

Returns array{minimum: float, objective: float}\|array{maximum: float, objective: float}

Errors Input error (code 1001).

See also Details

uniroot()

A root of f in [lower, upper] as R’s uniroot(): Brent’s method; f(lower) and f(upper) must not have the same sign. Returns the root, f(root), the iterations used and the estimated precision; E_WARNING and iter = maxiter when not converged. f receives one float and returns an int or float; an exception from f propagates. Nonfinite values during the search are replaced by +/-PHP_FLOAT_MAX, as R does, with one E_WARNING.

Phit\uniroot(
    callable $f,
    float $lower,
    float $upper,
    ?float $tol = NULL,
    int $maxiter = 1000,
): array
Parameter Type Default Description
$f callable required Function whose root is sought: takes one float and returns an int or float
$lower float required Lower end of the search interval
$upper float required Upper end of the search interval
$tol ?float NULL Default PHP_FLOAT_EPSILON ** 0.25, as R
$maxiter int 1000 Largest number of iterations

Returns array{root: float, f_root: float, iter: int, estim_prec: float}
