Model functions

Linear and generalized linear models from a formula or a numeric design. Result keys, inference, and algorithms are detailed in Model contracts; formula syntax in Model formulas.

Formula models

fit_ols()

Linear model from a formula, like R’s lm(): builds the model matrix and fits by least squares, weighted least squares when weights are given (as lm(weights = )), with offset() terms. Until phit 0.5, an array first argument (or named x:/y:) runs the deprecated matrix fit, Phit_ols_matrix(), with one E_USER_DEPRECATED; its result has no formula keys. Factor levels unused after deletion are dropped, as lm() does. Rank deficiency raises 1004 instead of R’s NA coefficients. Formula syntax and R differences: docs/formulas.qmd. Rows with null/NAN in any variable the formula uses are dropped with one E_WARNING (missing ‘raise’ rejects them); retained_rows/dropped_rows are original positions.

    mixed $data = NULL,
    string $missing = 'drop',
    mixed $weights = NULL,
    ?array $offset = NULL,

    ?array $y = NULL,
): array
Parameter Type Default Description
$formula mixed NULL R formula, e.g. ‘y ~ log(x) + f * z + offset(log(t))’ (deprecated until 0.5: a matrix x)
$data mixed NULL Named columns or factor descriptors; objects use toModelData(), else toColumns() (deprecated: y)
$missing string 'drop' ‘drop’ removes rows with null or NAN in any variable the model uses and warns once; ‘raise’ rejects them
$weights mixed NULL Positive prior weights aligned with the original rows, or a column name
$offset ?array NULL Deprecated matrix form only; in a formula write offset()
$intercept bool true Deprecated matrix form only; in a formula write - 1
$x ?array NULL Deprecated: use Phit_ols_matrix()
$y ?array NULL Deprecated: use Phit_ols_matrix()

fit_generalized_linear()

Generalized linear model from a formula, like R’s glm(): gaussian/identity (the OLS core), binomial/logit, binomial/probit and poisson/log (the matrix GLM cores). Binomial responses: 0/1, logical, factor/string (first level = failure), proportions with trial weights, or cbind(successes, failures). The empty link selects the canonical link. Formula syntax and R differences: docs/formulas.qmd. Rows with null/NAN in any variable the formula uses are dropped with one E_WARNING (missing ‘raise’ rejects them); retained_rows/dropped_rows are original positions.

model_matrix()

R-compatible model.matrix() for a formula over named columns: treatment contrasts (first level is the reference), contr.poly for ordered factors, R column names/term order, inline transforms, offset() and random-effect bars. Unused factor levels are kept, as in model.matrix(); x includes the “(Intercept)” column when present. Formula syntax and R differences: docs/formulas.qmd. Rows with null/NAN in any variable the formula uses are dropped with one E_WARNING (missing ‘raise’ rejects them); retained_rows/dropped_rows are original positions.

predict()

Predictions for new data from a fit_ols (formula), fit_generalized_linear, fit_mixed_gaussian or fit_mixed_logistic result, like R’s predict(): the fit’s formula is rebuilt over newdata with the fitted factor levels and poly() basis (its predvars key). A level the fit never saw is an error. Rows with missing predictors predict null and are listed in missing_rows. type ‘response’ applies the inverse link; seFit uses the delta method on that scale. Intervals (‘confidence’ or ‘prediction’, t with df_residual) are for fit_ols fits. Mixed fits add random effects of known groups (random: false gives population predictions; allowNewLevels predicts unseen groups at zero). GLM standard errors use the covariance at the final coefficients (docs/r-compatibility.qmd).

Phit\predict(
    array $fit,
    mixed $newdata,
    string $type = 'link',
    bool $seFit = false,
    string $interval = 'none',
    float $level = 0.95,
    bool $random = true,
    bool $allowNewLevels = false,
): array
Parameter Type Default Description
$fit array required A formula fit result (needs formula, coefficients, covariance, columns and predvars)
$newdata mixed required Named columns, as for the fit; the response may be absent
$type string 'link' ‘link’ (linear predictor) or ‘response’
$seFit bool false Also return standard errors of the predictions; fixed-effect fits only
$interval string 'none' ‘none’, ‘confidence’ or ‘prediction’
$level float 0.95 Confidence level of the interval
$random bool true Mixed fits: include random effects (lme4 re.form = NULL) or not (re.form = NA)
$allowNewLevels bool false Predict a group the fit never saw at the population level instead of raising 1001

Returns

array{
  fit: list<float|null>,
  se_fit?: list<float|null>,
  df?: int,
  residual_scale?: float,
  lower?: list<float|null>,
  upper?: list<float|null>,
  level: float|null,
  n_input: int,
  n_predicted: int,
  missing_rows: list<int>,
}

Errors Input error (1001), malformed fit, new levels, or unsupported options (1007).
