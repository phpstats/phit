Model functions

Linear and generalized linear models from a formula or a numeric design. Result keys, inference, and algorithms are detailed in Model contracts; formula syntax in Model formulas.

Formula models

fit_ols()

Fits a linear model from a formula, like R’s lm().

  • Builds the model matrix from named columns and fits by least squares, or by weighted least squares when weights is given, as lm(weights = ) does.
  • offset() terms in the formula are added to the linear predictor.
  • vcov accepts iid, HC0-HC3, one-way clustered HC0/HC1, or Newey-West covariance. Cluster inference uses G-1 df.
  • Factor levels left unused after missing rows are dropped are removed, as lm() does.
  • A rank-deficient design throws instead of returning R’s NA coefficients.
  • Rows with null or NAN in a variable the formula uses are dropped with one warning; missing: 'raise' rejects them instead. retained_rows and dropped_rows give the original row positions.

fit_iv()

Fit an instrumental-variable model by two-stage least squares.

  • Formula: y ~ exogenous | endogenous ~ excluded instruments. Only top-level bars split the parts.
  • Standard errors use structural residuals. First stages include partial R², Shea partial R², and Sanderson–Windmeijer F, with Wu–Hausman and Sargan tests in diagnostics.
  • vcov accepts iid, HC0-HC3, one-way cluster HC0/HC1, or Newey-West. Cluster inference uses G-1 df. IV diagnostics retain iid definitions. Under-identification and rank deficiency raise 1004. Random effects and offsets raise 1007.
  • Rows with null or NAN in a variable the formula uses are dropped with one warning; missing: 'raise' rejects them instead. retained_rows and dropped_rows give the original row positions.

fit_ridge()

Fit Gaussian ridge regression with glmnet alpha=0 scaling.

  • Penalty factors normalize over predictor columns. The intercept is unpenalized and unbounded.
  • Named or wildcard bounds apply on the original coefficient scale. At-bound coefficients have null uncertainty.
  • Standard errors and intervals condition on lambda. Estimates are biased and intervals are not coverage-valid.
  • Rows with null or NAN in a variable the formula uses are dropped with one warning; missing: 'raise' rejects them instead. retained_rows and dropped_rows give the original row positions.

cv_ridge()

Choose a ridge penalty by weighted cross-validation.

  • Explicit fold IDs align with original input rows and take precedence over nfolds and seed.
  • Grouped fold MSE and its standard error match cv.glmnet. The selected fit uses lambda_min.
  • The default path has 100 decreasing log-spaced values; explicit sequences must be strictly decreasing.
  • Rows with null or NAN in a variable the formula uses are dropped with one warning; missing: 'raise' rejects them instead. retained_rows and dropped_rows give the original row positions.

  • Factors use treatment contrasts with the first level as the reference; ordered factors use contr.poly.
  • Column names, term order, inline transforms, offset(), and random-effect bars follow R.
  • Unused factor levels are kept, as in model.matrix(), and x includes the (Intercept) column when present.
  • Rows with null or NAN in a variable the formula uses are dropped with one warning; missing: 'raise' rejects them instead. retained_rows and dropped_rows give the original row positions.

predict()

Predicts new data from a fit_ols(), fit_generalized_linear(), fit_mixed_gaussian(), or fit_mixed_logistic() result, like R’s predict().

  • The fit’s formula is rebuilt over newdata with the fitted factor levels and poly() basis, from the fit’s predvars key. A level the fit never saw throws.
  • A row with a missing predictor predicts null and is listed in missing_rows.
  • type: 'response' applies the inverse link, and seFit then uses the delta method on that scale.
  • interval: 'confidence' or 'prediction' adds lower and upper for fit_ols() fits, using t with df_residual.
  • Mixed fits add the random effects of known groups. random: false gives population predictions, and allowNewLevels predicts unseen groups at the population level.
  • GLM standard errors use the covariance at the final coefficients, which differs slightly from R’s predict.glm().
Phit\predict(
    Fit|array $fit,
    array|object $newdata,
    string $type = 'link',
    bool $seFit = false,
    string $interval = 'none',
    float $level = 0.95,
    bool $random = true,
    bool $allowNewLevels = false,
): array
Parameter Type Default Description
$fit Fit\|array required A formula fit, or its toArray() array, with the keys formula, coefficients, covariance, columns, and predvars
$newdata array\|object required Named columns, as for the fit; the response may be absent
$type string 'link' 'link' (linear predictor) or 'response'
$seFit bool false Also return standard errors of the predictions; fixed-effect fits only
$interval string 'none' 'none', 'confidence', or 'prediction'
$level float 0.95 Confidence level of the interval
$random bool true Mixed fits: include the random effects of known groups, as lme4’s re.form = NULL; false predicts at the population level, as re.form = NA
$allowNewLevels bool false Predict a group the fit never saw at the population level instead of throwing

Returns

Printing results

summary()

Prints a model fit in the layout of R’s print(summary(fit)), as text ending in a newline.

  • Takes the result of any model function: OLS and GLM fits, formula or matrix, and Gaussian and logistic mixed fits.
  • The coefficient table follows R’s printCoefmat(digits = 4) without significance stars. A linear model adds the residual standard error, R-squared, and the F statistic; a GLM adds the dispersion, deviances, and AIC; a mixed model adds its fit criteria and the random-effect variances, as lme4 prints them.
  • Matrix fits name their coefficients x1, x2, and so on, and leave out the lines that need a formula.

tidy()

Returns a fit’s coefficient table as columns, like broom’s tidy().

  • The columns are term, estimate, std_error, statistic, and p_value. confInt: true adds conf_low and conf_high at level.
  • Intervals are Wald intervals: t with df_residual degrees of freedom when the fit reports t statistics, and the normal distribution otherwise.
  • For mixed fits, the default effects: 'fixed' gives the fixed effects, and summary() prints the variance components.
  • effects: 'ran_vals' gives a mixed fit’s random effects, as broom.mixed does: group, level, term, estimate, and std_error, one row per term, column, and group. The estimates are the conditional modes and the standard errors their conditional standard deviations, as lme4::ranef(condVar = TRUE) reports them. Intervals use the normal distribution.

Fit and table objects

Every model function returns a fit object that implements Phit\Fit: LinearFit, GeneralizedLinearFit, MixedGaussianFit, or MixedLogisticFit, by the kind of model. echo $fit prints its summary. Reading a key, such as $fit['coefficients'], works as on the result array, and nested values are plain arrays. isset(), count(), foreach, and json_encode() work as on the array. Writing or unsetting a key throws LogicException; toArray() returns an array copy. summary(), tidy(), and predict() also accept that array.
